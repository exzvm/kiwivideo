# 03: 筛选收尾：一键清除、状态保留与无障碍

**What to build:** 当搜索与类型组合导致无结果时，空状态提供「清除筛选」操作，一次重置搜索词与类型并恢复完整片单。筛选条件在从详情页返回、屏幕旋转等配置变化、以及加载失败后重试时都保持不丢失。搜索框与类型 chip 具备读屏可识别的语义标签，使无障碍用户也能完成搜索与筛选。

**Blocked by:** 02: 类型筛选与组合筛选。
