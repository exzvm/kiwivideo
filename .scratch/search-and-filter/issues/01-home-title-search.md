# 01: 首页按片名搜索

**What to build:** 首页顶部出现搜索框，用户输入时海报网格按片名即时过滤——支持部分匹配、忽略英文大小写，空白输入视为不过滤；没有匹配时网格区显示「没有匹配的影片」；清空输入恢复完整片单。筛选状态由首页 ViewModel 持有，加载失败后重试时按当前搜索词重新应用。过滤在已加载片单上完成，不触发额外加载或转圈。

**Blocked by:** None (can start immediately).

**Status:** done

- [x] 输入部分片名能命中对应影片
- [x] 搜索忽略英文大小写
- [x] 输入为空或只有空格时显示全部影片
- [x] 清空搜索框后立即恢复完整片单
- [x] 无匹配时网格区显示「没有匹配的影片」提示
- [x] 过滤即时完成，不出现额外加载指示
- [x] 加载失败后点重试，当前搜索词保留并重新应用
- [x] 先扩展测试样例工厂，使其能构造不同标题与类型的影片（prefactor）
- [x] 单测覆盖：子串匹配、大小写、空白输入、无匹配
- [x] 原有首页加载成功 / 失败 / 重试用例保持通过

**Implementation note:** 搜索框目前只在加载成功后出现，因此「加载失败后重试保留搜索词」在 ViewModel 层已实现并有单测，但当前 UI 没有在错误态设置搜索词的路径；用户可见的状态保留行为由 03 继续覆盖。
