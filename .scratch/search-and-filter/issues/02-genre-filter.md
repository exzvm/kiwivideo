# 02: 类型筛选与组合筛选

**What to build:** 首页出现一行类型筛选 chip，包含「全部」以及来自完整片单的真实类型。点选某个类型后，网格只显示包含该类型的影片；「全部」取消类型筛选。类型筛选与已有的片名搜索同时生效，两者为「与」关系。类型集合从完整片单推导、去重并稳定排序，不随当前过滤结果变化。选中的 chip 有可见选中态，chip 行可横向滚动而不挤压布局。

**Blocked by:** 01: 首页按片名搜索。

**Status:** ready-for-agent

- [ ] 类型 chip 覆盖片单出现过的所有类型，去重且排序稳定
- [ ] 类型集合基于完整片单，选中某类型后其它 chip 不消失
- [ ] 选择某类型后只显示类型列表包含该类型的影片
- [ ] 点「全部」恢复不按类型筛选
- [ ] 搜索词与类型同时存在时取交集
- [ ] 选中 chip 有可见的选中态
- [ ] chip 行在类型较多时横向可滚动，不破坏首页布局
- [ ] 单测覆盖：类型过滤、「全部」取消、搜索与类型组合、类型集合来源
- [ ] 原有搜索相关用例保持通过
